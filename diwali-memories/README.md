# My Diwali Holiday Memories 🪔✨
> *"Little Moments, Beautiful Memories, Endless Happiness!"*

A modern, responsive, personal holiday diary web application built with **React**, **Vite**, **React Router DOM**, and **Tailwind CSS**.

---

## 📸 Personal Media Included
All uploaded authentic holiday photos and video are located in:
- `public/images/pic1.jpeg` – *Outdoor adventure with friend*
- `public/images/pic2.jpeg` – *Scooter outing road trip*
- `public/images/pic3.jpeg` – *Memorable moment with friends*
- `public/images/pic5.jpeg` – *Fun unfiltered moment with friend*
- `public/videos/pic4.mp4` – *Holiday video memory in motion with HTML5 video controls*

---

## 🌟 Pages & Architecture
- **Home (`/`)**: Diwali festive hero section with animated diyas, golden particle effects, authentic memories showcase, and celebration trigger buttons.
- **My Holiday Memories (`/memories`)**: Full gallery of the 4 original photographs with hover zoom, rounded corners, shadows, captions (*Beautiful Moments ❤️*, *My Happy Place*, *Friendship Forever*, *Unforgettable Memories*), and click-to-view lightbox.
- **Friends & Fun (`/friends`)**: Dedicated friendship album with squad memories, heartfelt reflections, and an embedded playable HTML5 video player for `pic4.mp4`.
- **Diwali Celebrations (`/celebrations`)**: Traditional celebrations featuring clay diyas, colorful rangoli, traditional wear, family blessings, bustling night bazaars, and safe sparklers.
- **Food & Sweets (`/sweets`)**: Traditional Diwali treats including Motichoor Laddu, Ghee Mysore Pak, Gulab Jamun, Crispy Murukku, Madras Mixture, and Adhirasam with tasting profiles and cultural traditions.
- **Photo & Video Gallery (`/gallery`)**: Comprehensive media gallery with category filter tabs (*All*, *Holiday Outings*, *Friendship*, *Celebrations*, *Sweets & Food*, *Videos*), hover zoom, and modal lightbox with Next/Prev navigation.
- **About My Holidays (`/about`)**: Personal holiday reflection ending with the signature quote: *"Every holiday gives me a new story, and every memory gives me a reason to smile!"*

---

## 🛠️ Tech Stack & Packages
- **React 18**
- **Vite 6**
- **React Router DOM 6**
- **Tailwind CSS 3** (Custom festive color palette, diya flame flicker animations, glassmorphism)
- **Lucide React** (Icons)
- **Canvas Confetti** (Festive fireworks & sparkler bursts)

## 🚀 How to Run the Project

1. Navigate to the project directory:
```bash
cd "C:\Users\acer\.gemini\antigravity\scratch\diwali-memories"
```

2. Install dependencies (already installed):
```bash
npm install
```

3. Start the Vite development server:
```bash
npm run dev
```

4. Open in your browser:
```
http://localhost:5173/
```
